02 · Contexto del problema

¿Qué es el fraude financiero y por qué representa un reto para los sistemas actuales?

El fraude financiero es cualquier acto que busca obtener un beneficio económico ilegítimo engañando a una persona, banco o sistema. El reto no es solo detectarlo, sino hacerlo entre millones de transacciones legítimas, en milisegundos, sin bloquear compras reales.

2.1

Tipos comunes de fraude financiero

💳

Tarjeta no presente

Compras en línea con datos de tarjeta robados.

🏦

Transferencias

Movimientos no autorizados entre cuentas.

🕵️

Suplantación de identidad

Apertura de cuentas con identidad robada.

🔄

Lavado de activos

Patrones de transacciones para ocultar origen ilícito.

2.2

El desafío del desbalance de clases

En un conjunto de datos real, el fraude suele representar menos del 1% de las transacciones. Un modelo que siempre prediga "no es fraude" tendría más del 99% de exactitud (accuracy) y, sin embargo, sería completamente inútil. Por eso, en este dominio se priorizan métricas como precisión (de lo que marco como fraude, ¿cuánto lo es realmente?) y recall (de todo el fraude real, ¿cuánto logré detectar?).

03 · Modelos de aprendizaje automático

Tres enfoques metodológicos para la detección de fraude

Cada algoritmo aborda el problema desde un ángulo distinto: aprender de ejemplos etiquetados, dividir el espacio de decisión, o detectar lo que se sale de lo normal.

Supervisado

Regresión Logística

Calcula la probabilidad de que una transacción sea fraudulenta a partir de variables como el monto, la hora o la ubicación, usando una función que convierte esa combinación en un valor entre 0 y 1.

VentajaRápido, interpretable, fácil de auditar en un banco.
LimitaciónSolo captura relaciones lineales entre variables.
Supervisado

Árboles de Decisión & Random Forest

Un árbol divide los datos con preguntas sucesivas ("¿monto > $2M?", "¿país distinto al habitual?"). Random Forest combina cientos de árboles entrenados con muestras distintas y promedia sus votos, reduciendo el sobreajuste de un árbol individual.

VentajaCaptura relaciones no lineales e interacciones entre variables.
LimitaciónUn árbol muy profundo memoriza el ruido (overfitting); Random Forest lo mitiga a costa de interpretabilidad.
No supervisado

Detección de anomalías (Isolation Forest)

En lugar de aprender "qué es fraude", aprende "qué es normal" y marca como sospechoso todo lo que se aísla fácilmente del resto de los datos. Es clave cuando hay pocos o ningún ejemplo etiquetado de fraude, o para detectar tipos de fraude nunca antes vistos.

VentajaNo depende de tener fraudes ya etiquetados; detecta patrones nuevos.
LimitaciónMás falsos positivos; requiere definir qué tan "anómalo" es suficiente.
04 · Caso de referencia

Un escenario cercano a la realidad del sector financiero

En una institución bancaria, cada transacción se evalúa en milisegundos. Un sistema de detección debe equilibrar seguridad, experiencia del cliente y cumplimiento operacional.

ESCENARIO

Transacción sospechosa

Una compra internacional de alto valor aparece en un horario inusual para el cliente.

RESPUESTA

Evaluación automática

El modelo asigna un puntaje de riesgo que permite decidir si se aprueba, bloquea o revisa manualmente.

IMPACTO

Decisión de negocio

La elección del umbral define si se evita fraude o si se afecta la experiencia del usuario.

06 · Glosario técnico

Términos clave del dominio

Falso positivo
Transacción legítima marcada incorrectamente como fraude.
Falso negativo
Transacción fraudulenta que el modelo no detecta.
Precisión
Proporción de alertas de fraude que efectivamente son fraude.
Recall (sensibilidad)
Proporción del fraude real que el modelo logra detectar.
Overfitting
Cuando un modelo memoriza los datos de entrenamiento y pierde capacidad de generalizar.
Dataset desbalanceado
Conjunto de datos donde una clase (el fraude) es mucho menos frecuente que la otra.
Isolation Forest
Algoritmo no supervisado que detecta anomalías aislando observaciones atípicas.
Umbral (threshold)
Valor de puntaje a partir del cual una transacción se clasifica como fraude.
