# OVA - Detección de Fraudes Financieros con Aprendizaje Automático

Este proyecto consiste en un Objeto Virtual de Aprendizaje (OVA) interactivo sobre la detección de fraudes financieros utilizando algoritmos de aprendizaje automático.

## Contenido
- Introducción al problema de fraude financiero
- Explicación del desbalance de clases
- Comparación entre modelos supervisados y no supervisados
- Laboratorio interactivo para ajustar umbrales de decisión
- Evaluación de aprendizaje

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Visualización
El contenido puede abrirse directamente en el navegador desde el archivo HTML principal.
